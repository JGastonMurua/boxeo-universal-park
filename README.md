# Boxeo Universal Park

Sitio web oficial de **Boxeo Universal Park**, gimnasio de boxeo y entrenamiento físico ubicado en Ramos Mejía, Buenos Aires.

## Stack

- React 18 + Vite
- CSS personalizado (sin frameworks UI)
- Google Fonts: Bebas Neue, Barlow Condensed, Barlow

## Desarrollo local

```bash
npm install
npm run dev
```

## Build para producción

```bash
npm run build
```

Los archivos generados quedan en `/dist`.
